# Електронний квиток monobank («Миколаївелектротранс»)

Точна 1:1 копія сторінки електронного квитка **monobank** (`pay.monobank.ua`)

---

## 🌟 Особливості

1. **Чистий оригінальний сайт**:
   - Відтворює саме саму веб-сторінку, як вона відкривається у мобільному браузері.
   - Оригінальний круглий логотип перевізника **КП «Миколаївелектротранс»** зверху.
   - Кнопка деталей квитка `(i)` у правому верхньому кутку.
   - Нескінченний анімований рядок цитати: `◆ Життя — цікаве, і мотивація то є сильна: філософія, психологія. Найголовніше — за...`
   - Назва перевізника, розділювач, час купівлі («Придбано 13 жовтня о 20:09»), кількість («1 квиток»).

2. **Зворотний відлік з 1:30:00**:
   - Таймер автоматично починає відлік з `1:30:00` (5400 секунд).
   - Щосекунди зменшується: `1:30:00` -> `1:29:59` -> `1:29:58`...
   - Живий пульсуючий зелений індикатор з м'якою анімацією.

3. **Оригінальний QR-код зі скріншота**:
   - Використано точний оригінальний QR-код зі скріншота разом із фірмовим котом monobank у центрі.
   - Номер квитка: `Номер: 164 142`.
   - Хвилястий перфорований край чека знизу (SVG).
   - Примітка: `Ви зможете повторно відкрити цю сторінку через історію браузера`.

4. **Керування параметрами**:
   - Маленька шестірня `⚙` у правому нижньому кутку дозволяє змінити час, дату, тривалість або скинути до початкових `1:30:00`.
   - Кнопку `⚙` можна приховати. Щоб показати знову: **потрійний клік на верхній логотип** або клавіші `Ctrl + Shift + S`.
